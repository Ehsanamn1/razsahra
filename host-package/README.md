# بستهٔ استقرار داخلی راز صحرا — وضعیت توسعه

این پوشه پایهٔ runtime مبتنی بر Node.js و MySQL 8 را فراهم می‌کند. **هنوز بستهٔ نهایی قابل‌تحویل به کاربر نیست**؛ API مدار به‌طور کامل به MySQL منتقل نشده و باید تست‌های end-to-end و ساخت ZIP انتشار اجرا شوند.

## نیازمندی میزبان
- Node.js 20 یا بالاتر
- MySQL 8 و دسترسی ساخت/خواندن/نوشتن دیتابیس
- امکان اجرای برنامهٔ Node.js دائمی از پنل هاست
- HTTPS فعال برای کوکی امن نشست

## اجرای آزمایشی در محیط سازگار
1. مقدارهای `.env.example` را در تنظیمات محیطی برنامه وارد کنید؛ فایل واقعی را در Git بارگذاری نکنید.
2. از پوشهٔ `host-package`، `npm install` اجرا کنید.
3. `npm run install:db` را اجرا کنید.
4. `npm start` را اجرا کنید.
5. خروجی فرانت‌اند سایت باید در `host-package/dist` قرار بگیرد؛ این پوشه از build اصلی و bundle مدار تولید می‌شود.
6. بعد از بالا آمدن سرویس، `/api/health` را بررسی کنید.
7. فقط پس از تنظیم `ADMIN_BOOTSTRAP_SECRET` تصادفی حداقل ۳۲ نویسه‌ای، مدیر اولیه را با `POST /api/auth/bootstrap-admin` بسازید و کلید را پس از آن حذف کنید.

## محدودیت‌های فعلی
- مسیرهای اصلی CMS و احراز هویت در Node/MySQL پیاده‌سازی اولیه شده‌اند، اما parity کامل با Workers هنوز تأیید نشده است.
- API مدار هنوز مستقل نیست؛ در صورت خالی بودن `MEDAR_API_ORIGIN` با پاسخ 503 صریح متوقف می‌شود. به همین دلیل این نسخه نباید برای استفادهٔ واقعی منتشر شود.
- نصب schema تکرارپذیر است و جدول‌ها را حذف نمی‌کند؛ با این حال قبل از هر انتشار باید از دیتابیس مقصد نسخهٔ پشتیبان گرفته شود.
- این فایل‌ها جایگزین تأیید سازگاری دقیق میزبان‌فا نیستند.
