# RAZ SAHRA — وب‌سایت شرکتی راز صحرا

وب‌سایت فارسی و راست‌چین برای **راهبران زنجیره ارزش صحرا** با برند تجاری **راز صحرا | RAZ SAHRA** و شعار **«از تأمین تا ارزش‌آفرینی»**.

## فناوری و ساختار
- وب‌سایت ایستا با HTML، CSS و JavaScript؛ بدون پایگاه‌داده، فریم‌ورک یا وابستگی به مرحله build.
- رابط کاربری واکنش‌گرا، فارسی با \`lang="fa"\` و \`dir="rtl"\`.
- تایپوگرافی Vazirmatn از Google Fonts و تصاویر نماینده از Unsplash.
- مسیرهای صفحه به‌صورت query-based پیاده‌سازی شده‌اند تا در GitHub Pages بدون تنظیمات rewrite کار کنند؛ برای نمونه \`?page=about\` و \`?page=partnerships\`.
- محتوای صفحه‌ها و مسیریابی در \`index.html\` قرار دارد؛ لایه طراحی تکمیلی در \`assets/raz-sahra-premium.css\` و تعاملات حرکتی در \`assets/raz-sahra-interactions.js\` نگهداری می‌شوند.
- موشن‌های ورود هنگام اسکرول، نوار پیشرفت مطالعه، ریزتعامل دکمه‌ها، واکنش‌های hover و پشتیبانی از \`prefers-reduced-motion\` پیاده‌سازی شده‌اند؛ بدون شمارنده یا آمار ساختگی.

## اجرا و استقرار
این پروژه مرحله build ندارد. برای مشاهده محلی، فایل \`index.html\` را در مرورگر باز کنید. برای استقرار، مخزن به GitHub Pages متصل می‌شود و گردش‌کار \`.github/workflows/pages.yml\` انتشار را پس از هر push به شاخه \`main\` انجام می‌دهد.

نشانی مورد انتظار پروژه:
https://ehsanamn1.github.io/razsahra/

پس از نخستین اجرا، وضعیت انتشار را از تب **Actions** مخزن و سپس **Settings → Pages** بررسی کنید. در صورت درخواست GitHub برای انتخاب منبع انتشار، گزینه **GitHub Actions** را انتخاب کنید.

## تصاویر و مجوز استفاده
- تصاویر نماینده از ایران استفاده شده‌اند و نباید به‌عنوان تصاویر تأسیسات متعلق به راز صحرا برداشت شوند.
- تصویر بلدرچین و تخم بلدرچین: حسین طاهوری / خبرگزاری تسنیم، با انتساب و پیوند مجوز Creative Commons Attribution 4.0.
- تصویر مزرعه پرندگان در دشت لار: مهدی کلهر، با انتساب و پیوند مجوز Creative Commons Attribution 3.0.
- انتساب‌ها و پیوند مجوزها در فوتر سایت قرار دارند. در صورت جایگزینی تصاویر، وضعیت مجوز و انتساب باید دوباره بررسی شود.

## فرم‌ها — محدودیت عمدی نسخه بدون backend
فرم‌های تماس و همکاری اعتبارسنجی سمت مرورگر دارند و یک فایل متنی محلی آماده می‌کنند. آن‌ها **اطلاعات را به شرکت ارسال نمی‌کنند**؛ هیچ ایمیل، شماره تماس، endpoint یا سرویس سمت سرور ساختگی در کد قرار داده نشده است. برای فعال‌سازی ارسال آنلاین، باید ایمیل رسمی یا endpoint معتبر شرکت مشخص و یک مسیر ارسال امن پیاده‌سازی شود.

## وضعیت صحت محتوا
- نام رسمی: راهبران زنجیره ارزش صحرا
- برند تجاری: راز صحرا / RAZ SAHRA
- شعار: از تأمین تا ارزش‌آفرینی
- آمار، مشتریان، مجوزها، نشانی، شماره تماس و حساب‌های اجتماعی تأییدنشده ساخته نشده‌اند.
- حوزه‌های آینده به‌صورت مسیر توسعه یا موضوع نیازمند ارزیابی مشخص شده‌اند.
- بخش دانستنی‌ها تا آماده‌شدن محتوای واقعی، حالت خالی روشن دارد.
- نشان هندسی فعلی یک پیاده‌سازی موقت و برداری در کد است، نه ادعای لوگوی ثبت‌شده. جایگزینی آن با فایل شفاف و نهایی برند ساده است.

## کارهای تکمیلی پیش از عرضه عمومی
1. تأیید لوگوی نهایی و فایل‌های مستقل برند.
2. افزودن ایمیل، شماره تماس و نشانی رسمی پس از تأیید.
3. تصمیم درباره میزبانی محلی فونت و تصاویر به‌جای منابع بیرونی.
4. اتصال فرم‌ها به مسیر ارسال امن پس از تعیین مقصد واقعی.
5. بازبینی حقوقی سیاست حریم خصوصی متناسب با سرویس‌های نهایی.
6. بررسی دسترس‌پذیری و مرورگرهای هدف پس از استقرار.
